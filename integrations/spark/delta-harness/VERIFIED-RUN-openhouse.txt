OpenHouse capability findings (Gate #0):

              incremental read; rollback_to_snapshot / set_current_snapshot procedures;
              transforms identity/bucket/truncate/years/months/days/hours
  rejected  : partition evolution (ALTER ADD/DROP PARTITION FIELD); void transform; days(date)

Physical MoR note: a MoR DELETE only adds a position-delete file when it matches a STRICT SUBSET
of a data file. When the predicate covers a whole data file, Iceberg legitimately drops the file
(metadata delete, no position delete) — so the discriminator seeds all rows into one file
(COALESCE(1)) and deletes a strict subset to make the physical outcome deterministic.

Run on JDK 17 against the embedded OpenHouseLocalServer + OpenHouseCatalog.
