### 1. The spec header cites a base spec that does not exist in the tree
- **location**: specs/tla/OpenHouseCommitRename.tla:6-9 (header comment; README.md:3-8 inherits the same framing)
- **principle**: The document stands on its own (STRUCTURE.md rule 4 — undefined insider terms)
- **claim**: the header grounds the module in "the OpenHouseCommit spec
  (which reproduced the stale-base snapshot-loss bug ... ) extended with a
  Renamer process", but no `OpenHouseCommit.tla` exists on this branch or on
  `main`; the base spec lives only in an unmerged docs branch the text never
  names.
- **evidence**: "This module is the OpenHouseCommit spec ... extended with a
  Renamer process"; `git grep -l OpenHouseCommit.tla` on the branch returns
  nothing outside specs/tla's own README/spec.
- **failure scenario**: a reader auditing the model (exactly the reader this
  directory exists for) searches the repo for the base spec to diff the
  extension against it, finds nothing, and cannot tell whether the commit-path
  half of the model was itself ever validated.
- **severity**: suggestion
- **confidence**: confirmed
- **reviewer**: writing-review
